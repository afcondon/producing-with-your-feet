MC6 protocol sniffer

Listens to everything the MC6 sends over USB and keeps the raw bytes. Point it at the Morningstar port, then start the editor and let it connect — macOS lets both this page and the editor hold the same MIDI input, so the editor's startup handshake is captured verbatim. That handshake is how the editor reads the device, which is the thing this app cannot currently do.

Requesting MIDI access…

Send a request and watch for the reply below. The device answered these function codes unprompted when the editor connected; what is not yet known is what the editor asked to get them. Each button is one guess at the request. Nothing here writes to the device — these are questions.

Sweeps walk one byte at a time and watch for any answer, which is faster and more reliable than guessing. F1 = 0x07 is skipped — that is the upload family, the one range known to write. Everything else is presumed-but-not-proven harmless, so take a fresh backup from the Morningstar editor before running these.
