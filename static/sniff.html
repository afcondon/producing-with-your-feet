MC6 protocol sniffer

Listens to everything the MC6 sends over USB and keeps the raw bytes. Point it at the Morningstar port, then start the editor and let it connect — macOS lets both this page and the editor hold the same MIDI input, so the editor's startup handshake is captured verbatim. That handshake is how the editor reads the device, which is the thing this app cannot currently do.
